# Day 1.2 samples — iFlow anatomy

Samples for the **Hello iFlow** and the **Customer Echo Service scaffold** from `day2_iflow_anatomy.md`.

| File | Purpose |
|---|---|
| `hello_response.json` | Static body the Hello iFlow returns |
| `hello_curl.sh` | Test command for the deployed Hello endpoint |
| `hello_content_modifier.md` | Content Modifier settings (Message Body + Message Header tabs) |
| `hello_iflow.iflw.xml` | Skeleton iFlow XML — HTTPS sender → Content Modifier → End |
| `customer_echo_scaffold.md` | Sender adapter config + placeholder body for the day-3 baseline |
| `adapter_settings.md` | HTTPS sender common settings (CSRF, role, MEP) |

> Substitute `<initials>` with your two-letter initials throughout. The trainer assigns these on Day 1.0.
